# A股行业轮动与资金流向监控看板

深色金融终端风格的 A 股行业轮动监控页，**每个交易日收盘后自动更新**。

🔗 在线访问：https://wangjun20251978.github.io/sector-rotation-monitor/

## 功能

- **大盘概览**：上证 / 深成 / 创业板 / 科创50 / 沪深300 / 北证50 六大指数实时点位与涨跌幅
- **行业涨跌热力图**：16 个申万一级行业，色深表示涨跌幅强度（**A股惯例：涨红跌绿**）
- **主力资金排行**：行业主力资金净流入 / 净流出双向条形对比
- **风格轮动**：大盘价值 ↔ 小盘成长、红利 ↔ 硬科技、大盘 ↔ 小盘等多组相对强弱
- **行业全景表**：全部行业涨跌幅与主力净额一览

## 数据来源与更新机制

- 行情数据来自公开行情接口（东方财富 / 腾讯，双源备份）
- GitHub Actions 每交易日 **15:40（北京时间）**自动抓取并重新生成页面
- 接口全部不可用时，保留上一个交易日的页面（不会出现空白页）

## 本地运行

```bash
python scripts/build.py
```

无需安装任何第三方依赖，仅使用 Python 标准库。
